# Подключение реальных ИИ-советов к «Листу» 2.0

**Статус: сервер не развёрнут, онлайн-ИИ по умолчанию не работает.** GitHub Pages не может безопасно хранить OpenAI API key. Требуется личный серверный Cloudflare Worker.

## Что отправляется
Только после отдельного согласия и нажатия кнопки: месяц, валюта, суммы доходов/расходов, активы и остатки, названия категорий и агрегированные расходы, бюджетные лимиты, процентные ставки/остатки накопительных счетов, суммарный прогресс целей, сумма ближайших регулярных платежей. Не передаются имена счетов, реквизиты, заметки, отдельные операции и истории транзакций. **Названия категорий и суммы передаются провайдеру ИИ (OpenAI API).**

По умолчанию отправка выключена. Поставщик модели может обрабатывать запрос по собственным условиям; даже `store:false` не означает гарантии полного отсутствия хранения в каждой инфраструктурной системе.

## Развёртывание Worker

Нужны доступ к Cloudflare Workers и отдельный аккаунт с оплатой OpenAI API.

1. Склонируйте репозиторий и перейдите в каталог `worker`.
2. Скопируйте `wrangler.toml.example` в `wrangler.toml` (при необходимости замените имя Worker).
3. В терминале выполните:
```bash
npx wrangler login
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put ACCESS_TOKEN
npx wrangler deploy
```
4. В `OPENAI_API_KEY` укажите свой **секретный ключ OpenAI API**. Для `ACCESS_TOKEN` используйте совершенно другой случайный секрет длиной минимум 24 символа, например созданный командой `openssl rand -hex 32`. Никогда не сохраняйте секреты в GitHub, HTML или настройках PWA.
5. Wrangler выдаст URL вида `https://list-finances-advice.<ваш-subdomain>.workers.dev/`.
6. В «Листе» откройте **Ещё → Онлайн-советник**, вставьте URL и сохраните его. Убедитесь, что Worker принадлежит вам.
7. Перейдите в **Аналитика → ИИ-анализ**, ознакомьтесь с описанием отправляемых агрегатов, отметьте согласие и нажмите «Получить анализ». Введите `ACCESS_TOKEN`. Он существует только в памяти открытой сессии, не в localStorage.

## Защита и стоимость
- Worker отвечает только на запросы с Origin `https://314-pixel.github.io`; origin-проверка не заменяет авторизацию. Дополнительно всегда требуется личный `ACCESS_TOKEN`.
- `OPENAI_API_KEY` хранится в Cloudflare Secrets. Браузер не получает этот ключ.
- Worker проверяет структуру агрегатов и ограничивает объём и время запроса. Настройте **Cloudflare rate limiting, квоты/лимиты оплаты OpenAI** и мониторинг, чтобы не допустить неконтролируемых расходов.
- Этот пример предназначен для одного владельца, не для публичного многопользовательского сервиса. При утечке ACCESS_TOKEN немедленно замените секрет.
- Модель по умолчанию `gpt-4.1-mini`, название можно менять в `OPENAI_MODEL`. Возможность вызова и стоимость зависят от актуального доступа вашего API-аккаунта.

Результат проверки `node tests/worker.test.mjs`: запросы к реальному OpenAI не использовались, все ответы заглушены. **Не считать это подтверждением боевой интеграции.**
