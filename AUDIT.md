## Финансовая модель
**Бюджеты:** исходное поле `limit` — общий лимит календарного месяца; `monthLimits[YYYY-MM]` — индивидуальная сумма для конкретного месяца. Проводки с типом transfer/goalAdd/goalTake не считаются доходами и расходами.

**Накопительный счёт:** ставка `interestRate` трактуется как процент годовых, `interestStart` — старт неучтённого периода. Ежедневная оценка: `max(0, остаток после операций дня) * interestRate / 36500`. Сумма по дням от начала периода до **начала текущего дня**. В расчёте не учитываются налоги, изменение ставки задним числом, индивидуальные правила банков, капитализация неподтверждённых процентов. Прогноз на 30 дней: `max(0, текущий остаток) * rate * 30 / 36500`.

Кнопка начисления предлагает оценку, после чего владелец вводит **фактически зачисленную банком сумму**; только она создаёт доходную проводку, увеличивает баланс и меняет начало следующего периода. Реальные суммы могут отличаться от модели.

## Данные и приватность
Ключ localStorage остался `list-finances-v1`, версия документа — `1`. Старые записи читаются без переноса на сервер. Новая версия добавляет поля; **старая версия HTML при сохранении может отбросить новые поля**. Перед обновлением сохраняйте JSON-копию. Нет отдельного шифрования, облачной синхронизации, подключения к банкам, автоматического расчёта налогов или Face ID.

Собственный Worker обязателен для ИИ; без Worker онлайн-ИИ недоступен. Клиент передаёт агрегаты только по согласию, токен доступа не сохраняется. См. `AI_SETUP.md`.

## Не проверено
Браузерная автоматизация в текущем окружении не смогла открыть localhost/file URL: `ERR_BLOCKED_BY_ADMINISTRATOR`. Поэтому реальные UI-клики и offline lifecycle на Safari iOS, фактический GitHub Pages deployment, реальные тарифы/начисления банков и настоящий OpenAI API не тестировались. Логические проверки **не являются end-to-end тестами**.

Найдённые ограничения, оставленные сознательно: месяц не нормализуется по неполному периоду; нет банковских выписок; доходность накоплений — оценка; PWA localStorage может исчезнуть при очистке данных; ИИ требует отдельного платного серверного компонента.
