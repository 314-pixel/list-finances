# Импорт SMS 900 через «Команды» iPhone

В «Листе» появился автономный импорт текстов финансовых SMS. Это **не подключение к банку** и **не автоматическое списание**. Каждая операция сначала открывается как **не сохранённый черновик**, который пользователь проверяет и сохраняет вручную.

## Способ 1. Через буфер обмена — предпочтительно для приватности

1. В «Командах» выберите «Автоматизация» → «Сообщение» → отправитель **900** (если iOS позволяет выбрать короткий номер).
2. Режим запуска: **«После подтверждения»**.
3. Действия: «Получить содержимое» из **Вход команды** (тип Message; выберите содержимое сообщения, не отправителя), «Скопировать в буфер обмена», затем «Открыть URL» `https://314-pixel.github.io/list-finances/`.
4. В «Листе» нажмите **«Импорт SMS 900» → «Из буфера обмена» → «Распознать»**; если Safari не даёт прочитать буфер, вставьте текст вручную.
5. Проверьте счёт, тип операции, категорию, сумму и дату; нажмите «Сохранить».

Текст SMS в этом способе не попадает в URL; при этом другое приложение с разрешением доступа к буферу обмена потенциально сможет его прочитать. Из-за ограничений iOS кнопка «Открыть URL» может открывать Safari вместо установленной PWA.

## Способ 2. Сразу открыть заполненный черновик

Создайте автоматизацию «Сообщение» от 900 с режимом **«После подтверждения»**. Добавьте действия:

1. «Кодировать URL» — входом укажите **содержимое сообщения (Shortcut Input → Content)**, а не номер отправителя.
2. «Текст»: `https://314-pixel.github.io/list-finances/#sms=` и **сразу после знака =** динамическую переменную из «Кодировать URL», без пробела.
3. «Открыть URL» — передайте полученный текст.

«Лист» удаляет фрагмент `#sms=...` из адреса при открытии и заполняет форму, **не сохраняя запись автоматически**. Фрагмент URL не передаётся HTTP-серверу GitHub Pages, но может оставаться в данных самой «Команды», истории/синхронизации ссылок или отображаться до обработки. Для особо чувствительных SMS используйте способ 1.

В зависимости от версии iOS отправитель **900** может не отображаться в стандартном выборе контактов. В таком случае используйте ручной импорт или более узкий фильтр по устойчивым словам банковского уведомления, но **не** настраивайте срабатывание на любые сообщения без проверки.

**Безопасность:** не импортируйте одноразовые коды, не публикуйте SMS и не используйте их для входа в банки. Поддерживаются типовые формулировки: покупка, оплата, списание, зачисление, пополнение и перевод. Парсер может ошибаться в направлении перевода и категории; обязательна проверка формы. Не импортируйте одно SMS дважды.

## Offline и совместимость

Новый ресурс `sms-import.js` кэшируется сервис-воркером версии v5. Сначала запустите приложение с интернетом и проверьте «Ещё → Доступ без интернета», затем попробуйте авиарежим. Перед обновлением создайте JSON-резервную копию. Формат хранилища `list-finances-v1` не менялся.

Локальная проверка парсера: `node tests/sms-import.test.cjs`. Полноценная автоматизация в физическом iOS Shortcuts и получение реального сообщения с короткого номера отдельно не проверены.
