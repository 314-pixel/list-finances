# Лист — автономный финансовый дневник для iPhone

**Версия:** 1.0  
**Язык:** русский  
**Тип:** автономная HTML-страница + Progressive Web App (PWA), без IPA, App Store, регистрации, сервера данных и внешних библиотек.

## Файлы

- `index.html` — **всё приложение в одном файле** (интерфейс, стили, логика, хранение).
- `manifest.webmanifest` — имя и параметры установки PWA.
- `service-worker.js` — кэширование файлов приложения для запуска после установки без интернета.
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — значки для экрана «Домой».

## 1. Как открыть один HTML-файл

Можно открыть `index.html` в браузере, который разрешает выполнение JavaScript и работу `localStorage` для локального файла. Интернет для финансовых функций не нужен. На компьютере достаточно открыть файл в браузере.

**Особенность iOS:** просмотр HTML из «Файлов»/Quick Look и открытие `file://` на iPhone могут ограничивать JavaScript, скачивание файлов и постоянное локальное хранение. Поэтому для **надёжной установки и хранения на iPhone** предпочтительнее способ № 2: PWA по HTTPS. Один локальный HTML-файл нельзя считать полноценно установленным iOS-приложением.

## 2. Как установить как приложение на iPhone (рекомендуется)

1. Распакуйте ZIP. Разместите **все** файлы из папки рядом друг с другом на любом статическом HTTPS-хостинге, например GitHub Pages, Cloudflare Pages или Netlify. Backend и база данных не требуются.
2. Откройте опубликованный адрес `https://.../index.html` в **Safari на iPhone**.
3. Нажмите «Поделиться» → «На экран „Домой“» → при наличии включите «Открывать как веб-приложение» → «Добавить».
4. Открывайте «Лист» по значку на экране «Домой». После первого успешного запуска PWA-файлы могут быть доступны без интернета благодаря service worker.

На GitHub Pages: создайте репозиторий, поместите файлы в корень ветки `main`, перейдите в **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**. После публикации откройте адрес Pages в Safari. Репозиторий может быть публичным: вы публикуете только **пустой исходный код**, а не внесённые впоследствии финансы — данные хранятся на вашем устройстве.

**Важное различие:** данные локального HTML, Safari и установленной PWA могут храниться в отдельных контейнерах. Чтобы перенести записи, экспортируйте JSON из старого экземпляра и импортируйте его в новом.

## 3. Использование

- «+» — расходы, доходы, переводы между счетами, пополнение и вывод накоплений.
- «История» — поиск и фильтрация по типу и месяцу, редактирование и удаление записей.
- «План» — бюджеты на календарный месяц, накопительные цели, регулярные платежи.
- «Аналитика» — структура трат, графики, сравнение месяцев и персональные подсказки на основе ваших данных.
- «Ещё» — счета, категории, валюта, тема, копии и импорт/экспорт.

Правила регулярных платежей **не списывают средства автоматически**: при наступлении срока нажмите «Учесть». Неиспользованные и просроченные правила остаются в списке.

**Накопления:** перевод со счёта в цель уменьшает остаток счёта и увеличивает остаток цели; общий капитал не изменяется. Пополнения целей не считаются расходами, а вывод из целей не считается доходом.

**Валюта:** выбор RUB/EUR/USD/KZT/BYN/UAH меняет только формат и символ денежных сумм. Конвертации по курсу валют нет; для корректного учёта используйте одну учётную валюту.

## 4. Резервная копия и восстановление

В приложении откройте **«Ещё» → «Копия JSON»**, сохраните файл в «Файлы» (желательно в защищённую папку). JSON включает счета, операции, категории, бюджеты, цели, правила и настройки. Через **«Восстановить»** выберите этот JSON; текущий дневник будет **полностью заменён**. «Выгрузить CSV» экспортирует журнал операций для таблиц.

Рекомендуется создавать резервную копию регулярно, перед сменой адреса/способа установки, очисткой Safari или удалением приложения. HTML-приложение не имеет облачного бэкапа и не восстанавливает записи автоматически.

## 5. Конфиденциальность и ограничения

- Данные хранятся в **localStorage конкретного браузера/веб-приложения**, не отправляются на сервер и не привязаны к банковским счетам.
- Дополнительного шифрования на уровне приложения и пароля **нет**. Не передавайте JSON посторонним; он содержит записи в открытом виде.
- Очистка данных браузера, удаление PWA и ограничения хранилища устройства могут удалить записи.
- Персональные рекомендации — локально рассчитанные правила бюджетирования, а не финансовый консультант или прогноз доходности.
- Service worker кэширует только файлы интерфейса; записи пользователя не попадают в этот кэш.
- PWA требует HTTPS для регистрации service worker. Самостоятельно открытый HTML-файл работает без него там, где браузер разрешает локальный JavaScript.

Создано как автономное приложение. Функции проверены в автоматизированном браузерном тесте с мобильным размером экрана; фактические ограничения Safari зависят от iOS и способа запуска.

## Автономная работа на iPhone (после обновления)

1. Откройте `https://314-pixel.github.io/list-finances/` с интернетом через Safari.
2. Добавьте страницу «На экран „Домой“» (если предложено, включите «Открыть как веб-приложение»).
3. **Один раз откройте значок приложения с интернетом**, затем зайдите в «Ещё» → «Доступ без интернета».
4. Дождитесь надписи «Готово для офлайна»; если не появилась, нажмите «Проверить».
5. Проверьте запуск с экрана «Домой» в авиарежиме.

При установке iPhone может хранить данные веб-приложения отдельно от Safari. Поэтому проверять готовность к офлайн-работе следует именно внутри установленного приложения. После очистки кэша автономный запуск придётся подготовить снова. Экспортируйте резервную копию JSON, чтобы не потерять личный журнал.
