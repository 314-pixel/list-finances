# Лист 2.0 — финансовый дневник для iPhone

Приложение: https://314-pixel.github.io/list-finances/

Автономный финансовый журнал на русском языке с оформлением в эстетике iOS Liquid Glass. HTML + PWA без IPA, без регистрации и банковской синхронизации.

## Что нового
- «План → Бюджеты»: явная кнопка **«Изменить»** рядом с категорией. Можно установить общий месячный лимит или индивидуальный лимит для выбранного календарного месяца. При необходимости исключение сбрасывается.
- «Ещё → Мои счета»: **Накопительный счёт** с годовой ставкой, датой начала расчёта, оценкой неучтённых процентов и прогнозом на 30 дней. Нажмите «Учесть проценты» и введите сумму, фактически зачисленную банком. До подтверждения прогноз не увеличивает баланс.
- «Аналитика → ИИ-анализ»: запрос персональных советов с согласия пользователя, только через отдельно развернутый личный Cloudflare Worker. По умолчанию **ИИ не подключён**. Локальные советы автономны.
- Обновлённые полупрозрачные карточки, более читабельные формы Safari, темы, safe-area, поддержка уменьшения анимации.

## Установка
1. Включите GitHub Pages → Settings → Pages → Deploy from a branch → main → /(root).
2. На iPhone откройте https://314-pixel.github.io/list-finances/ через Safari.
3. «Поделиться» → «На экран Домой» → «Добавить».
4. Один раз откройте установленную иконку с интернетом, зайдите в «Ещё» → «Доступ без интернета» и дождитесь «Готово для офлайна». После обновления PWA может потребоваться повторный запуск.
5. Проверьте в авиарежиме. ИИ в авиарежиме недоступен.

## Данные и бэкап
Сохранён прежний ключ localStorage `list-finances-v1` и формат JSON версии 1. Новая версия читает старый дневник. **Перед обновлением экспортируйте JSON в «Ещё»**. Старую версию не следует использовать после внесения новых процентов/месячных бюджетов — она может отбросить новые поля.

Данные по умолчанию не синхронизируются с облаком и не шифруются дополнительным паролем. Очистка хранилища Safari или удаление PWA может удалить дневник. Файловая HTML-версия и установленная PWA могут использовать разные хранилища.

## ИИ
См. [AI_SETUP.md](AI_SETUP.md). API-ключ провайдера ИИ держится в секрете Cloudflare Worker, не в GitHub. Для доступа нужен личный токен; клиент просит явного согласия перед каждым запросом и передаёт только агрегаты. При отсутствии Worker работает только локальная аналитика.

## Проверки и ограничения
См. [AUDIT.md](AUDIT.md): 11 проверок финансовой модели и 5 проверок защищённого прокси на моках. Браузерные проверки iOS Safari/настоящего Cloudflare Worker **не проводились**.

Для тестов Node.js: `node tests/logic.test.cjs`, `node tests/worker.test.mjs`.

Это личный финансовый дневник и справочные расчёты, не профессиональная инвестиционная консультация.
